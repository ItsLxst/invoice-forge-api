# 🧾 Invoice Forge
A backend API that takes customer and item data as JSON, validates it, and generates a PDF invoice — returned directly in the response.
🔗 **[Live Demo (Swagger UI)](https://invoice-forge-api.onrender.com/docs)**

Note: hosted on Render's free tier, the app may take ~30 seconds to wake up on first request.

---
## ✨ Features
- Single endpoint (POST /invoices/) that accepts a JSON invoice payload (customer info + line items)
- Request validation via Pydantic — malformed or missing fields are rejected with a 422 before any PDF is generated
- Server-side PDF generation with ReportLab: title, customer details, an itemized table, and a computed total
- The generated PDF is returned directly in the response — no separate "get link then download" step
- Interactive API docs auto-generated by FastAPI at /docs (Swagger UI) and /redoc
- API key authentication via x-api-key header to prevent public abuse
---
## 🛠️ Technologies
- **Framework:** FastAPI (Python)
- **Validation:** Pydantic
- **PDF Generation:** ReportLab

## 🚀 Getting Started
### Prerequisites
- Python 3.10+
- pip
### Installation
bash
git clone https://github.com/ItsLxst/invoice-forge-api
cd invoice-forge-api
python -m venv venv
source venv/bin/activate # Windows: venv\Scripts\activate
pip install -r requirements.txt
python main.py

Open http://127.0.0.1:8000/docs to try the API interactively.
---
## 🎮 Usage
Send a POST request to /invoices/ with a JSON body like:
json
{
"customer": {
"customer_name": "Jane Doe",
"customer_email": "jane@example.com"
},
"items": [
{ "name": "Web Design", "quantity": 1, "price": 500.00 },
{ "name": "Hosting (1 year)", "quantity": 1, "price": 120.00 }
]
}

bash
curl -X POST "http://127.0.0.1:8000/invoices/" \
-H "x-api-key: your_api_key_here" \
-H "Content-Type: application/json" \
-d '{"customer":{"customer_name":"Jane Doe","customer_email":"jane@example.com"},"items":[{"name":"Web Design","quantity":1,"price":500.00}]}' \
--output output.pdf

The response is the generated PDF file itself.
